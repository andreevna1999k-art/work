# Шаблон ЗВИЧАЙНОГО гест-поста (статті 1–10 і 21–25)

Як образці justa.com.ua / fg-life.com.ua / gram-news.com.ua і наші статті 1–10.
- Обсяг: 3 000–3 500 знаків без пробілів (мінімум 2 000).
- H1 + 5–6 H2 + «Висновок». Без H3, таблиць, FAQ, «Юридичного коментаря».
- Вступ-сцена: 2–3 короткі фрази («Лист від банку. Потім дзвінок…») + «Розберімося».
- Абзаци короткі, бувають в одне речення. 1–2 списки по 4–6 пунктів.
- Закони — максимум 1–2 згадки (назва + стаття), без посилань. Можна й без них.
- Посилання одне: у H2 за темою (безанкорні — голий URL; 21–25 — анкор керівника дослівно, веде на /kompanii/).
- Тон: порадник для читача на «ви», без «я-юрист».
