# Гест-пости: як працювати (читати першим)

Одна сесія = одна стаття. Не тягнути історію старих чатів.

1. Відкрий папку сайту, напр. `lawagency.kiev.ua/`.
2. Прочитай лише: `RULES.md` → рядок статті в `STATUS.md` → її стиль у `STYLES.md` → потрібні норми в `LAWS-*.md`.
3. Для еталону тону й структури відкрий ОДИН приклад з `examples/` (не всі).
4. Напиши статтю в `articles/NN-slug.md`, прожени `python3 tools/build.py articles/NN-slug.md > /dev/null` (покаже знаки, H2, посилання).
5. Онови рядок у `STATUS.md`. Коміт + пуш у робочу гілку.

Мова спілкування з користувачкою: російська. Тексти статей: українська (окремі статті — як указано в STATUS).
Нічого не публікувати на сайти. Не вигадувати факти, кейси, цифри, цитати.
