## Стиль копірайтингу

Джерело манери: підручник «Фінансове право» (за ред. Кучерявенка, Дмитрик, НЮУ, 2019). Тон: доктринальний, але зрозумілий; авторське «ми/додамо». Побудова: теза → пояснення методу/принципу → «До цього додамо, що …» → «До того ж можна стверджувати і про зворотний вплив …» → «Таким чином …». Роль приватного кредитора й держави пояснювати через принцип, а потім практику. Лексика: правовідносини, суб'єкт, імперативний, диспозитивність (давати простішим словом). Фірмові звороти: «Слід наголосити, що …», «Отже, …». Уникати: теоретичних відступів без практичного висновку, жирного. Приклад: «Слід наголосити: списання боргу — це правова процедура, а не втеча від кредитора. До цього додамо, що закон ставить умови. Отже, спершу з'ясуємо, чи боржник їм відповідає.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
