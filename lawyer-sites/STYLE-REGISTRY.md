# Реєстр стилів сайтів юристів (читати перед кожним новим сайтом)

Мета: ~24 персональних сайти юристів, **усі з унікальним стилем**. Жоден стиль, шрифтова пара, hero-композиція чи палітра не повторюються. Перед створенням нового сайту: переглянути таблицю нижче, обрати **вільний** стиль (або вимагати новий референс від замовниці) і одразу додати рядок у реєстр.

## Загальні правила (діють для всіх сайтів)
- Мова текстів: українська (локаль `uk`). Тексти — без вигаданих фактів: **не писати фальшиві відгуки, цифри статистики, регалії, кейси**. Порожні блоки лишати з написом-заглушкою, заповнює замовниця.
- **Усе заокруглене** (панелі 28–40 px, картки 18–28 px, кнопки-таблетки з круглою стрілкою ↗), навіть якщо в референсі кути прямі.
- Структура головної: 1) hero (фото + Title + H1 «ПІБ — юрист по …» + кнопка) 2) Про мене 3) Послуги 4) Результати (фото + опис, поки порожні) 5) Відгуки (місце під плагін замовниці) 6) футер «Контакти» (телефон, Telegram, адреса, години, карта Google з міткою). Усі кнопки → Telegram юриста.
- Title сторінки = H1 (точний текст дає замовниця). Унікальний description. Обовʼязково JSON-LD **Schema Person** (без AggregateRating/Review, якщо відгуки не справжні).
- Мобільна версія обовʼязково продумана: hero — фото зверху з градієнтом, заголовок накладається знизу, кнопки на всю ширину, картки в 1 колонку, ряд кейсів гортається вбік.
- Контраст: перевіряти `tools/contrast.py` (WCAG ≥ 4.5 для тексту, ≥ 3 для великого). Не лишати колір заголовків «успадкованим»: **тема WordPress перебиває колір h1–h3 на чорний** → у CSS обовʼязково `h1,h2,h3{color:inherit}` + явні кольори; також `a{text-decoration:none}`.
- Публікація: сторінка WordPress через REST (`/wp-json/wp/v2/pages`), один блок `wp:html`, шаблон теми `page-blank` (власний порожній шаблон без шапки/футера, створюється через `/wp/v2/templates`: `<!-- wp:post-content {"layout":{"type":"default"}} /-->`). Статус спочатку `draft`. Meta description у `<head>` без SEO-плагіна не потрапляє (лише в тіло) — пропонувати Yoast/Rank Math.
- Не використовувати фото з підписами/помилками; кадрувати окремо. Не ставити однакові фото підряд.
