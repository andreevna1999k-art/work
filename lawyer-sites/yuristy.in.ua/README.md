## Стиль копірайтингу

Джерело манери: «Практикум з цивільного процесуального права України» (КНЕУ ім. Гетьмана). Тон: навчальний, діловий, через кейс-задачу. Побудова: «Ситуація» (2–3 речення з умовними даними) → «Питання: Чи може …?» → «Відповідь» із посиланням на норму та кроком дії (яку заяву подати, в який строк). Типові питання: «В якому порядку …», «Чи має право …», «Складіть заяву …». Лексика: судовий наказ, стягувач, боржник, заперечення, скасування. Уникати: вигаданих реальних клієнтів, обіцянок результату, жирного. Приклад: «Ситуація: боржник отримав судовий наказ через вісім днів. Питання: чи може він його оскаржити? Відповідь: так, протягом встановленого строку. Строк і форму заяви звіряємо за ЦПК.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
