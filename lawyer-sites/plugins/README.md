# Плагін відгуків (WP Personal Reviews, шорткод `[react_reviews]`)
- Архів: `wp-reviews-plugin.zip` (папка `wp-reviews-plugin`, код від керівника без змін). Автор у файлі: ILLIA PIHOVYCH.
- УВАГА: плагін сам вимикається, якщо його папка називається `wp-personal-reviews`. Не перейменовувати.
- Встановлення: адмінка → Плагіни → Додати новий → Завантажити плагін → вибрати zip → Встановити → Активувати. Через REST API zip поставити не можна.
- Показ на сторінці: шорткод `[react_reviews]` (у блоці wp:html працює). На сторінці один блок.
- Відгуки: меню «WP Відгуки» в адмінці (схвалити, змінити дату, видалити, режим карусель/список, ліміт). Відвідувачі лишають відгук формою на сторінці, він іде на модерацію.
- Оформлення під сайт: CSS-файл стилю в папці сайту (S1: `boychuk/reviews-s1.css`), підключається в build.py з `--plugin`; сам плагін не змінюємо.
- Відомі зауваження: публічний ajax `get_reviews` віддає й непідтверджені відгуки (фронтенд фільтрує); у `get_reviews_admin` немає перевірки прав, лише nonce.
