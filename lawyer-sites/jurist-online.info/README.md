## Стиль копірайтингу

Джерело манери: «Порадник клініциста: правила надання правової допомоги споживачам фінансових послуг» (ЧНУ ім. Федьковича). Тон: практичний, допомагаючий, звернення на «Ви». Побудова: «Алгоритм дій» → нумеровані кроки → питання-тест до читача («Чи підписували ви договір?») → норма короткою цитатою («Відповідно до … закону …») → зразок документа. Пояснення починати з ситуації споживача, не з норми. Лексика: споживач, фінансова послуга, кредитодавець, претензія. Фірмові звороти: «Крок 1. З'ясуйте …», «Тест на …», «Перевірте себе: …». Уникати: теорії без дії, жирного. Приклад: «Крок 1. З'ясуйте, чи брали ви цей кредит. Запитайте себе: чи підписували договір? Чи приходив код у СМС? Крок 2. Надішліть запит до бюро кредитних історій.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
