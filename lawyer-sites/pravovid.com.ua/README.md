## Стиль копірайтингу

Джерело манери: навчальний посібник «Виконавче провадження» (Ю. Білоусов, 2005). Тон: процесуальний, точний, як довідник виконавця. Побудова: «У разі …» як зачин процедури → «Відповідно до ст. … Закону …» → перелік вимог «має бути зазначено: • …; • …» → підсумок «Отже, X — це …». Кожну процедуру описувати за схемою: підстава → хто діє → строк → наслідок. Лексика: виконавчий документ, стягувач, боржник, державний виконавець, постанова. Фірмові звороти: «У разі …», «Вимоги до … встановлено …». Уникати: приблизних строків без перевірки закону, жирного. Приклад: «Постанова про арешт має містити: • дату й номер; • дані боржника; • суму стягнення. У разі невідповідності її можна оскаржити. Отже, арешт — це накладення обмеження на кошти.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
