## Стиль копірайтингу

Джерело манери: підручник «Фінансове право» (Х. Бехруз, К. Мануїлова; за ред. О. Дмитрик, НЮУ, 2022). Тон: нормативний, послідовний, без розмовності. Побудова: «Відповідно до …» → коротка цитата норми у лапках → «При цьому …» → «Отже, підставами/умовами є …»; «У разі …» як початок правил; «Так само …» для аналогій. Складні поняття розкладати на підстави й обмеження. Лексика: позичальник, заборгованість, погашення, списання, кредитні кошти. Уникати: розмовних слів, оцінок, жирного. Приклад: «Відповідно до закону, списання коштів потребує підстави. При цьому підставою може бути договір або рішення суду. Отже, спершу перевірте, на якій підставі списали кошти.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
