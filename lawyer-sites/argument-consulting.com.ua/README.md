## Стиль копірайтингу

Джерело манери: підручник «Договірне право України» (Кириченко, Кириченко, Куракін, 2024). Тон: академічно-практичний, підручниковий, багато «тобто». Побудова: поняття («Під … розуміють …») → сторони → предмет → форма → зміст/обсяг прав і обов'язків; норми цитувати з виділеним уривком «…» і номером статті; перелік умов як 1) 2) 3). Застереження «Слід зазначити, що …» та приклад у дужках «(наприклад, …)». Лексика: істотні умови, форма договору, зобов'язання, виконання, припинення. Уникати: сленгу, довгих цитат, жирного. Приклад: «Пролонгація — це продовження строку договору, тобто зміна строку, а не боргу. Слід зазначити, що змінюють договір письмово (наприклад, додатковою угодою). Сторони визначають новий графік.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
