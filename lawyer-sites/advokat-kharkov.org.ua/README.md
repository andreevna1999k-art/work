## Стиль копірайтингу

Джерело манери: практикум «Цивільно-процесуальне право України» (Т. Тодорошко, 2014). Тон: стислий, перевірочний, без зайвих слів. Побудова: питання-тест (чи є обов'язковою участь…?) → варіанти а) б) в) → правильна відповідь і одна норма. У статті використовувати блок «Перевірте себе» (2–3 питання) та короткі «питання — відповідь» під H2. Часто ставити прямі питання («Чи є … ?»). Лексика: апеляція, касація, строк, підстава, скарга. Уникати: довгих міркувань без питання, жирного. Приклад: «Чи можна оскаржити рішення суду після місяця? а) ні; б) так, за поважної причини; в) лише касацією. Правильно: б). Потрібне клопотання про поновлення строку.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
