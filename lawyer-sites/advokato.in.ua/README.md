## Стиль копірайтингу

Джерело манери: «Аналіз судової практики інституту неплатоспроможності фізичних осіб» (Г. Григорян, проєкт PRAVO-Justice, ЄС, 2021). Тон: аналітичний, експертний, без пафосу. Побудова: проблема → як по-різному вирішують суди («Аналогічний висновок робить суд у справі № …») → «Отже, є підстави вважати, що …» → «Рекомендації». Умовний приклад із сумою цифрами й словами («10 000 (десять тисяч) гривень»), позначений як ілюстрація. Риторичне питання на початку: «Чи є …?». Лексика: неплатоспроможність, план реструктуризації, кредитор, зборами кредиторів. Уникати: оцінок без справи, жирного. Приклад: «Чи може кредитор змінити голосування, відмовившись від застави? Суди відповідають по-різному. Отже, є підстави вважати, що важливий розмір вимог. Рекомендація: перевірте реєстр вимог.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
