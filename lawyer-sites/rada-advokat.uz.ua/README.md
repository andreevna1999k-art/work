## Как пересобрать и залить
```
python3 build_wp.py home-live.html wp-live.html 1901
python3 build_wp.py results-page.html wp-results.html 1916
```
Потом отправить содержимое на `POST /wp-json/wp/v2/pages/<ID>` (шаблон `elementor_canvas`). Сборка оборачивает страницу в `<!-- wp:html -->` и убирает комментарии/переносы между тегами, иначе WordPress вставляет `<p>`/`<br>` внутрь вёрстки.
