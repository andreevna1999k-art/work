## Стиль копірайтингу

Джерело манери: посібник «Юридичні клініки на захисті прав споживачів фінансових послуг: судова практика і навички консультування» (НаУКМА, 2020). Тон: практичний аргументатор, структурований. Побудова: «Щодо недійсності …» → нумерація 1., 1.1. → норма («Відповідно до ч. 1 ст. …») → «У нашому випадку …» → «Практичні поради та способи захисту». Для кожного твердження: норма, факт, вивід. Лексика: недійсність, істотні умови, електронний підпис, доказ, позивач. Фірмові звороти: «Тож відповідно до …», «Що в нашому випадку дотримано/порушено». Уникати: загальних порад без норми, жирного. Приклад: «1. Щодо умов договору. 1.1. Електронний підпис. Одноразовим кодом підписано лише договір. Тож перевіряємо, чи охоплює підпис правила банку. У нашому випадку це означає запит журналу підписання.» Правила головреда для всіх: речення 5–14 слів (проза до 20), без жирного, прямий висновок на початку розділу. З книжки беремо лише манеру, не теми й не цитати. Приклади лише ілюструють манеру: факти й норми звіряти.
