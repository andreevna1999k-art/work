# Шаблони Stories-обкладинок (1080×1920)

Файли a2…e2.html — п'ять композицій (02, 07, 08, 03, 01 з промта). Портрет — вирізаний `cut.png` (прозорий фон).
Для нового юриста: покласти його вирізане фото як `cut.png`, змінити заголовок у html, запустити
`NODE_PATH=$(npm root -g) node render.js a2 b2 c2 d2 e2` — PNG з'являться поруч.
Вирізка: `pip install rembg`, модель `isnet-general-use`, alpha matting (див. історію сесії).
Шрифти: Noto Serif Black, Roboto Condensed Black, Noto Sans SemiBold (локально в fonts/).

## v3 (поточний стиль, референси Forbes / Business / Business Frontiers)
f1…f5.html + base2.css + fit.js. Гігантське слово за головою (`.fit`, підганяється під 936 px), атмосферний фон (боке, глоу, зерно),
4 виноски з тексту статті (`.co`), заголовок, підзаголовок, рядок автора, плашка заклику. Кожен юрист має свою палітру/акцент;
5 обкладинок одного юриста — один каркас, різні колір, кадр, шрифт гігантського слова. Усі виноски беруться ТІЛЬКИ з тексту статті.
Рендер: `NODE_PATH=$(npm root -g) node render.js f1 f2 f3 f4 f5`. Фото: `cut2x.png` (вирізка, 2x, різкість).

## v4 (поточний): стиль «договір» + кольори сайту юриста
`gen.py` генерує g1…g5.html з одного шаблону. Параметри юриста — у CSS `:root` (--acc, --acc2, --ink, --dk) і градієнт `.bg`.
Для Бойчука палітра з design-system сайту: бронза #C9A262/#E0C38F, слонова кістка #F3EBDD, темно-коричневий #17130E.
Для іншого юриста: підставити палітру його сайту, його вирізане фото (`cut2x.png`), ПІБ/посаду, домен у `.foot`, тексти виносок зі СТАТТІ.
Рендер: `python3 -I gen.py && NODE_PATH=$(npm root -g) node render.js g1 g2 g3 g4 g5`.

## Кравченко (rada-advokat.uz.ua): стиль за референсом Business Frontiers
`gen_kr.py` -> k1…k5.html. Гігантське слово/цифра за головою, тикер + дата-плашка зверху, виноски зліва, блок автора + виноска справа,
заголовок стопкою (Noto Sans 800, авто-підбір кегля), акцентна лінія + підзаголовок, плашка заклику, скайлайн. Палітра сайту:
#042A41 / #004671 / #EAFFFF / #C2E8FF / #7298AF. Вирізка фото: rembg isnet-general-use + прибирання крісла за кольором (див. сесію).

## Гончарук (ukrjurist.com.ua): світлий стиль за референсом Forbes
`gen_gn.py` -> g1…g5.html. Світлий кремовий фон + скайлайн + золота мережа, гігантське слово за головою (Noto Serif Black), виноски колонками

## Борисов (uchet.com.ua): темний стиль за референсом GQ
`gen_bo.py` -> b1…b5.html. Playfair Display (Didone) + Noto Sans. Гігантське слово зліва за головою, блок-виноска справа (вирівняний по правому краю) із плашкою-тегом,
блок зліва, великий заголовок антиквою з «приглушеним» сполучником, тонування фото (warm/neutral/cool). Палітра сайту: #0D1017 / #7A6D3C / #D2C48F / #F5F3EC.
Лише одне якісне фото юриста (hero, 640px) — інші два з ресторану, не використані.
