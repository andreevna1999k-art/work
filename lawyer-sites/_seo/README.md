# Meta title / description для статей (4 сайти, 42 статті)
Джерело: рядки «Title:» і «Description:» на початку кожного Google-документа. Файл `meta-title-description.csv` (кодування UTF-8 з BOM, відкривається в Excel/Google Sheets).
Ліміти: title до 60, description до 160 символів. Три рядки було трохи довшими й скорочено (позначено в колонці «Примітка»): legaladdress №5 (title), uchet №2 (description), uchet №5 (title).
